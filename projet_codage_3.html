Développement Suivea v3

Intégration front-end d'une page Suivea v3 et mise en place d'une base composants pendant le stage MMI2 chez Docaposte.

Rôle
Développement front-end en binôme
Contexte
Stage MMI2 · Docaposte · Suivea
Période
Mai 2021 - Juillet 2021
Type
Développement web

Résumé du projet

Dans le prolongement de la refonte graphique, j'ai participé au développement web de Suivea v3. L'objectif était de transformer des maquettes validées en écrans fonctionnels, tout en posant une base de composants réutilisables pour accélérer les évolutions du produit.

Le périmètre couvrait à la fois la fidélité visuelle (typographie, espacements, hiérarchie) et la maintenabilité du code pour les futures pages.

Objectif technique

  • Structurer une page de référence des composants (couleurs, typo, tailles, règles UI)
  • Intégrer une page Suivea v3 fidèle aux maquettes validées
  • Maintenir une cohérence avec le design system interne de l'équipe
  • Préparer une base front-end réutilisable pour réduire le temps d'intégration des écrans suivants

Ce que j'ai développé

J'ai d'abord développé une page socle regroupant les composants et styles de référence, puis nous avons réalisé l'intégration des écrans en binôme sur cette base commune.

  • Structuration HTML des blocs métier avec hiérarchie claire
  • Mise en place de classes CSS réutilisables (grille, boutons, champs, cartes)
  • Ajustements fins de spacing, tailles de texte et alignements pour coller aux maquettes
  • Vérification de cohérence visuelle entre les écrans et les états d'interface

Organisation en binôme

Le travail était découpé par lots (structure, composants, intégration, retours), avec des points réguliers pour aligner le rendu final. Cette organisation a permis d'éviter les divergences de style et de garder une progression continue malgré les itérations.

Difficultés & ajustements

  • Traduction précise maquette → code : ajustements progressifs des marges, tailles et alignements
  • Homogénéité entre écrans : normalisation des composants pour éviter les variations visuelles
  • Contraintes de planning : priorisation des éléments critiques avant les raffinements

Résultats

  • Base composants opérationnelle pour accélérer les futurs développements
  • Écran Suivea v3 intégré de manière fidèle et validé en interne
  • Méthode de travail plus robuste sur l'intégration UI en contexte professionnel
