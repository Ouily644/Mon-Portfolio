Project summary

During my internship at Playback Solutions, I designed and developed a web platform to automate the reception, validation and classification of large audio deliverables such as stems before routing them into Dropbox.

Goal: replace a long, error-prone and loosely structured manual process with a system that was reliable, secure and aligned with a strict technical delivery guide. The project had to simplify the experience for artists while also reducing manual handling on the production side.

Context

Artists used to send stems via WeTransfer. The team then had to:

  • Check the email, find the WeTransfer link, open the page, click download and wait for the transfer to finish
  • Verify compliance with the technical guide
  • Fix naming issues
  • Manually organize the files inside Dropbox

Each delivery usually represented around 2 to 3 GB of data.

This workflow created several recurring issues:

  • Time lost on repetitive tasks
  • Human errors during sorting and routing
  • Misnamed or incomplete files
  • Frequent delivery issues against technical requirements

Integrating the mandatory delivery guide

The company works with a detailed audio delivery guide covering:

  • Required audio format
  • Tempo and time structure
  • Stem separation rules
  • Strict naming conventions
  • Mandatory metadata

I integrated this guide directly into the platform so that part of the quality control would happen before the upload itself. The user has to:

  1. Open every section
  2. Read them
  3. Check a mandatory validation box

Without that step, access to the upload form stays blocked.

Developed solution

I designed the platform around a simple but strict flow, with checks from the first step and automated Dropbox routing.

  • Password-based access by group such as artist or production
  • Mandatory guide validation before the upload becomes available
  • Structured upload form with required fields to reduce delivery mistakes
  • Automatic routing to a specific Dropbox folder according to the user group
  • Dropbox API integration with secure token handling
  • Regular token regeneration to avoid losing access
  • Automatic file organization to remove most of the manual sorting

Flow organization

  1. The user validates the guide and accesses the form
  2. The system applies checks and required fields
  3. The files are sent to the correct Dropbox space according to the user group
  4. The final organization is automated to avoid manual sorting

Technical challenges

Handling large files at around 3 GB

Stems often exceeded 300 MB per file, with several files per delivery. I had to adapt the upload logic to guarantee:

  • Stable transfers on large volumes
  • Reliable request handling against the Dropbox API
  • Behavior robust enough to avoid failures on heavy deliveries

Dropbox root vs shared folders

One critical issue was that the Dropbox root differs depending on whether the target is a shared folder. Early tests were sending files to the wrong place.

To fix that, I had to:

  • Understand Dropbox namespace logic
  • Adapt path management
  • Correct the mapping between groups and shared folders

This was decisive: without that fix, the automation seemed to work while still placing the files in the wrong space. It was the most formative technical problem of the project.

Reliability & security

  • Regular API token regeneration to avoid access interruptions
  • Upfront validation to reduce non-compliant files
  • Group-based routing to reduce destination errors
  • Structured upload process for better traceability

Results

  • Processing time divided by four
  • Manual sorting removed for most deliveries
  • Reduction in naming and routing mistakes
  • More professional, documented and structured workflow
  • Better artist accountability before upload

Technologies & approach

  • Web stack: HTML, CSS and JavaScript
  • Dropbox API
  • Token-based authentication with regular regeneration
  • Guide validation and conditional access logic
  • Large file upload handling
  • Use of AI as a development assistant for exploration, base code generation and debugging, with manual adaptation and validation

What this project helped me develop

  • Understanding of a real operational need
  • Ability to turn production constraints into a technical solution
  • Integration of an external API
  • Handling large volumes of data
  • Problem-solving in a real production environment

This project shows my ability to connect technical rigor, operational reliability and ease of use in a professional context.
